## Python Implementation

The python implementation of the post office is a cli application

### Example Usage

```bash
python main.py ../sample_input.txt
```

This works with any file in the correct format like this

```csv
1. 4,4,.009,02893,08516
```

Or as shown in the [sample test file](sample_input.txt)
